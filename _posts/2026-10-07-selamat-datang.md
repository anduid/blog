Ini tulisan pertama. Blog ini berjalan di GitHub Pages, jadi setiap kali saya menyimpan (commit) file baru, situs ikut diperbarui.

<!--more-->

## Apa yang akan ditulis di sini

Catatan harian, hal yang baru dipelajari, dan cerita singkat dari proses membangun aplikasi. Tidak ada jadwal tetap.

## Cara menulis tulisan baru

1. Buat file di folder `_posts/` dengan nama `TAHUN-BULAN-TANGGAL-judul.md`.
2. Isi bagian atas file dengan *front matter*: judul, deskripsi, tanggal, dan tags.
3. Tulis isi dengan Markdown, lalu commit.
